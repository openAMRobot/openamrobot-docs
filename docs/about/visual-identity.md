# Visual identity

This documentation site uses the Botshare visual system to make OpenAMRobot recognisable and consistent across technical and public-facing material.

## Core palette

| Role | Colour | Hex |
| --- | --- | --- |
| Primary | Botshare blue | `#0072C6` |
| Accent | Botshare orange | `#FF9500` |
| Background | White | `#FFFFFF` |
| Supporting neutral | Gray | `#A6A6A6` |

Blue is the primary navigation, link and structural colour. Orange is an accent for calls to action and highlights; it is not used for ordinary body text on white because that combination does not provide adequate contrast.

## Typography

- **Headings and brand display:** Space Grotesk, with a system sans-serif fallback.
- **Body and interface text:** Inter, with a system sans-serif fallback.
- **Code:** the documentation theme's monospace stack.

The site does not fetch these fonts from a third-party font service. This avoids an unnecessary external request and allows the documentation to remain privacy-conscious and reliable offline. Where the named fonts are not installed, the declared system fallbacks are used.

## Names and marks

“OpenAMRobot,” “Botshare,” their logos and associated product names identify the project and its operator. Open-source licences grant rights in the covered source material; they do not by themselves grant permission to imply endorsement, affiliation or certification, or to misuse project branding.

For proposed brand use, partnerships, press assets or logo files, contact [info@botshare.ai](mailto:info@botshare.ai).

## Asset handling

Use only an approved, unmodified source asset. Do not redraw a logo from screenshots, stretch it, change its colours, add effects or place it where contrast is insufficient. Keep original vector or transparent source files outside generated site output and optimise only published copies.

The visual constants on this page reflect the available Botshare brand specification. If Botshare issues a newer approved brand standard, that standard supersedes this page and the website theme should be updated with it.
