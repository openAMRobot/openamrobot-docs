# Intralogistics

**For:** operations teams, integrators and partners evaluating internal material movement.

Typical workflows include point-to-point delivery, line-side supply, warehouse support, patrol and movement of small loads between named locations.

| Pilot question | Evidence to collect |
| --- | --- |
| Is the route navigable and repeatable? | Map, obstacle and recovery runs |
| Is the payload compatible? | Mass, dimensions, stability and handling |
| Can staff request and monitor work? | Mission and UI workflow test |
| What human intervention remains? | Intervention count and reason |
| Does it create value? | Labor time, waiting, errors and throughput |

**Relevant capabilities:** navigation, mapping, named locations, missions, docking, operator UI and external task APIs.

!!! warning "Do not automate a vague process"
    Define source, destination, frequency, payload, traffic, hand-off and acceptance criteria before selecting hardware.
