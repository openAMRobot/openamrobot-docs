# Project status

This page separates documentation structure from the maturity of the capability it describes. A published route can be planned while its owning repository continues implementation and validation.

| Area | Documentation state | Capability signal | Owning source |
| --- | --- | --- | --- |
| Foundations | Structured; expansion in progress | Stable concepts, release-specific implementation | [Documentation hub](https://github.com/openAMRobot/openamrobot-docs) |
| Mobile platform software | Repository-grounded overview available | Active development | [openamr-platform-sw](https://github.com/openAMRobot/openamr-platform-sw) |
| Firmware | Repository-grounded overview available | Active development | [openamr-platform-fw](https://github.com/openAMRobot/openamr-platform-fw) |
| Hardware | Repository-grounded overview available | Revision validation in progress | [openamr-platform-hw](https://github.com/openAMRobot/openamr-platform-hw) |
| Operator interface | Task map and screenshots available | Active; verify the current release | [openamrobot-ui](https://github.com/openAMRobot/openamrobot-ui) |
| Manipulation and demonstration | Learning architecture available | Experimental and developing | [Repository ecosystem](reference/repositories.md) |
| Academy | Program structure available | Commercial delivery outside this site | [Academy](academy/index.md) |

Capability badges on individual pages remain the more specific signal. Exact versions, parameters, source and contracts remain canonical in the owning repository.
