# Domain Expert track

Use this track when you understand the real process but are not a robotics specialist. The App and documentation should help you operate, monitor, demonstrate, correct and judge supported robot workflows safely.

## Planned route

1. Complete the safety and platform orientation foundations.
2. Learn daily checks, robot states and remote operation.
3. Run maps, locations and missions.
4. Capture, review and evaluate supported demonstrations.
5. Diagnose operator-level failures and escalate with useful evidence.

**Primary destination:** [Use the robot](../use/index.md).
