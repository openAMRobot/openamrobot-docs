# Integrator track

Use this track to configure and deploy OpenAMRobot for a real site or workflow.

## Planned route

1. Understand the architecture, interfaces and safety boundaries.
2. Configure networking, sensors, navigation, docking and manipulation.
3. Integrate external systems and site procedures.
4. Establish acceptance tests, monitoring and recovery behavior.
5. Document the deployed configuration and hand it over to operators.

**Primary destination:** [Configure the platform](../configure/index.md).
