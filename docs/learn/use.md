## First operator journey

<div class="oamr-path"><span>Start</span><b>→</b><span>Check state</span><b>→</b><span>Load map</span><b>→</b><span>Select mission</span><b>→</b><span>Run</span><b>→</b><span>Verify</span></div>

<div class="oamr-grid">
<article class="oamr-card"><h3>Drive & map</h3><p>Teleoperate safely, create a map, save it and understand what the robot sees.</p></article>
<article class="oamr-card"><h3>Locations & poses</h3><p>Work with names that describe the site and task, not robotics coordinates.</p></article>
<article class="oamr-card"><h3>Missions</h3><p>Build, schedule, run, cancel and review reusable task sequences.</p></article>
<article class="oamr-card"><h3>Blockly</h3><p>Create behavior with conditions, loops and robot actions without conventional code.</p></article>
<article class="oamr-card"><h3>Monitor</h3><p>Read robot state, battery, map, logs, events and execution history.</p></article>
<article class="oamr-card oamr-card--accent"><h3>Recover</h3><p>Recognize when something is wrong, stop safely and follow the correct escalation path.</p></article>
</div>
