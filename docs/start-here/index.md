## What OpenAMRobot is

OpenAMRobot is an open-source robotics ecosystem operated by **Botshare LTD**. It combines a modular mobile platform, ROS 2 software, embedded firmware, open hardware, shared interfaces, an operator UI and a developing manipulation and Embodied AI layer.

Its operating idea is simple: **the person who understands the work should be able to operate and teach the robot without first becoming a robotics engineer**.

## Simulation or hardware?

| Start with simulation when… | Start with hardware when… |
| --- | --- |
| You are learning navigation, missions or APIs | You must validate mechanics, wiring, sensors or safety |
| You want a reproducible software environment | You are preparing a real deployment or demonstration |
| Hardware is not yet available | You completed the pre-power safety checks |

!!! warning "Know the boundary"
    Simulation does not validate power, wiring, sensing noise, traction, mechanical tolerances, emergency behavior or site safety.
