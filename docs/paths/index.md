# Paths

Choose the path that matches what you need to accomplish now. A person can move between paths as their responsibilities grow.

| Path | Start here when you want to… | First verified outcome |
| --- | --- | --- |
| [Domain Expert](domain-expert.md) | Apply process knowledge without becoming a robotics engineer | Run and assess a supported workflow |
| [Beginner](beginner.md) | Learn robotics and OpenAMRobot fundamentals | Complete a first simulation |
| [Integrator](integrator.md) | Adapt and deploy a system at a site | Produce an accepted deployment configuration |
| [Builder](builder.md) | Assemble and own the physical platform | Pass bring-up and acceptance checks |
| [Developer](developer.md) | Extend software, firmware, hardware or interfaces | Submit a tested, documented change |
| [Entrepreneur](entrepreneur.md) | Build a service or product around the ecosystem | Validate a customer problem and delivery model |
