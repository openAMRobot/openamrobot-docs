# Builder path

For people assembling, bringing up and maintaining the physical platform.

<div class="oamr-path"><span>Prepare</span><b>→</b><span>Source</span><b>→</b><span>Assemble</span><b>→</b><span>Bring up</span><b>→</b><span>Calibrate</span><b>→</b><span>Accept</span></div>

Follow [Build](../build/index.md) from workspace preparation through assembly, first power-on, calibration and acceptance. Use `openamr-platform-hw` for canonical CAD, BOM and manufacturing source; `openamr-platform-fw` for embedded firmware; and `openamr-platform-sw` for ROS 2 integration.

**Finish when:** the build has passed documented electrical, motion, sensing and software acceptance checks and has a recorded configuration baseline.
