# Beginner path

For a newcomer who wants a structured introduction before choosing a more specialized path.

<div class="oamr-path"><span>Robot anatomy</span><b>→</b><span>ROS 2</span><b>→</b><span>Simulation</span><b>→</b><span>Navigation</span><b>→</b><span>Docking</span></div>

1. Start with [Foundations](../foundations/index.md) and [ROS 2 in an afternoon](../foundations/ros2/index.md).
2. Use the Docker quickstart in [`openamr-platform-sw`](https://github.com/openAMRobot/openamr-platform-sw#quickstart--simulation-navigation--docking).
3. Launch Gazebo Harmonic, Nav2 and the AprilTag-bundle docking pipeline.
4. Verify that the robot can navigate, dock and undock in simulation.

**Capability boundary:** this verifies the current experimental simulation stack, not physical power, wiring, sensing, traction or site safety.
