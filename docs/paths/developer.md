# Developer path

For contributors extending code, firmware, hardware, simulation, UI or shared interfaces.

<div class="oamr-path"><span>Choose a repository</span><b>→</b><span>Set up</span><b>→</b><span>Implement</span><b>→</b><span>Test</span><b>→</b><span>Document</span><b>→</b><span>Contribute</span></div>

Start with the [repository ecosystem](../reference/repositories.md) and change the repository that owns the relevant contract. The active mobile stack is ROS 2 Jazzy with Gazebo Harmonic, Nav2 and AprilTag-bundle docking. Manipulation and upper-body work is currently planned and simulation-first.

**Finish when:** the change is tested, documented, license-compliant and submitted through the project contribution workflow with required DCO and contributor-agreement checks.
