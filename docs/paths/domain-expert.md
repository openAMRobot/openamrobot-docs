# Domain Expert path

For people who understand the task, process or quality criteria and need to operate or teach a supported robot workflow.

<div class="oamr-path"><span>Safety</span><b>→</b><span>Operate</span><b>→</b><span>Demonstrate</span><b>→</b><span>Review</span><b>→</b><span>Judge</span></div>

1. Learn the [safe operating boundary](../foundations/safety/index.md).
2. Use [driving](../use/driving/index.md), [missions](../use/missions/index.md) and [monitoring](../use/monitoring/index.md).
3. Plan, capture and review a [demonstration](../use/demonstration/index.md).
4. Record task-specific acceptance criteria and decide whether the result is usable.

**Finish when:** you can execute a bounded workflow safely, recognize failure states and explain the outcome using process criteria.
