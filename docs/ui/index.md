# Operator interface

[openamrobot-ui](https://github.com/openAMRobot/openamrobot-ui) is the active browser-based operator interface for OpenAMRobot.

The repository owns installation, build, test, configuration and route documentation. This site records its ecosystem role:

- presents robot state and controls to operators;
- communicates with the ROS 2 system through declared interfaces;
- does not replace physical safety controls or independent validation; and
- supersedes the archived OpenAMR UI repositories.

Use the repository README for current commands and supported versions.
