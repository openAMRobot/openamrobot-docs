# Repository index

This is the canonical map of the OpenAMRobot GitHub organization. Repository status reflects GitHub archival state; technical maturity is stated separately.

## Governance and hubs

| Repository | Role | Status |
|---|---|---|
| [openAMRobot/.github](https://github.com/openAMRobot/.github) | Organization governance, contribution, security, IP, CLA and templates | Active |
| [openamrobot-docs](https://github.com/openAMRobot/openamrobot-docs) | Durable ecosystem documentation and documentation standard | Active |
| [openamrobot-release](https://github.com/openAMRobot/openamrobot-release) | Versioned multi-repository release assembly and provenance | Active |
| [openamrobot-manifest](https://github.com/openAMRobot/openamrobot-manifest) | Cross-repository source manifest | Active |

## Mobile base

| Repository | Role | Status |
|---|---|---|
| [openamr-platform-sw](https://github.com/openAMRobot/openamr-platform-sw) | ROS 2 Jazzy mobile-base software stack | Active |
| [openamr-platform-fw](https://github.com/openAMRobot/openamr-platform-fw) | Embedded mobile-base firmware | Active |
| [openamr-platform-hw](https://github.com/openAMRobot/openamr-platform-hw) | Mobile-base CAD, electrical and manufacturing source | Active |
| [openamrobot-ui](https://github.com/openAMRobot/openamrobot-ui) | Operator web interface | Active |
