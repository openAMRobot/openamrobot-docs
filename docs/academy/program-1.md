# Program 1 · Operate & Train

Program 1 is the Domain Expert entry point. It teaches people who understand a task or process to operate the supported robot, demonstrate work, review captured episodes and judge whether the outcome is acceptable.

| For | Starting point | Verified outcome |
| --- | --- | --- |
| Domain experts and operations teams | No robotics coding required | Run a bounded workflow safely and produce a reviewed demonstration |

## Learning sequence

<div class="oamr-path"><span>Understand</span><b>→</b><span>Operate</span><b>→</b><span>Show</span><b>→</b><span>Correct</span><b>→</b><span>Judge</span><b>→</b><span>Plan a pilot</span></div>

Participants learn safe start-up and shutdown, missions and docking, the interface and monitoring workflow, guided teleoperation, demonstration capture, episode review and outcome-based acceptance. Training claims are limited to currently supported, bounded workflows; arbitrary task learning is not implied.
