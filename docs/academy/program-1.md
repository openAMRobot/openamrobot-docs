## Intended audience

- operators and supervisors;
- process owners and domain experts;
- customer teams evaluating an OpenAMRobot workflow;
- non-robotics specialists entering through the Domain Expert track.

## Learning outcome

Participants should be able to start and stop the robot safely, understand its operating state, run a supported mission, demonstrate a bounded task, review the result and recognize when to stop or escalate.

## Proposed modules

| Module | Practical outcome |
| --- | --- |
| Platform orientation | Identify the robot, App, controls, operating states and safety boundary |
| Daily operation | Complete pre-use checks and run a supported mission |
| Demonstration workflow | Capture and review a task demonstration |
| Correction and judgment | Identify an unacceptable result and provide structured feedback |
| Recovery | Respond safely to common operator-level failures |
| Practical assessment | Complete a supervised end-to-end operating scenario |

!!! info "Development status"
    The detailed curriculum, duration, prerequisites, assessment rubric and supported workflows will be added as the operating and demonstration pipelines mature.
