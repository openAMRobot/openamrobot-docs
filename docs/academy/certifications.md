# Practical certifications

Botshare Academy certifications are intended to verify demonstrated capability, not only course attendance.

| Certification | Candidate demonstrates |
| --- | --- |
| Certified Robot Operator | Safe start-up, mission execution, monitoring and recovery |
| Certified Robot Trainer | Task demonstration, review, correction and evaluation |
| Certified Robot Builder | Assembly, bring-up, calibration and acceptance |
| Botshare Robot Product Engineer | Technical customization plus a reviewed capstone |

!!! warning "Open source and certification are separate"
    Anyone may learn from and use OpenAMRobot under its licenses. Official Botshare Academy certification, assessments and verification are separate commercial services.

Certificate issuance and public verification will be handled through the Academy platform.
